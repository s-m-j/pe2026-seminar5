# Глоссарий: система учёта курсовых работ

| Термин | Определение |
|---|---|
| Работа | Курсовая работа студента: набор файлов, загруженных как одно целое |
| Версия работы | Набор файлов, загруженный студентом за одну загрузку; версии не перезаписываются |
| Черновик | Версия работы, загруженная студентом до финальной сдачи (фигурирует в FR-05) |
| Статус работы | Состояние проверки: «Не просмотрено», «Требуется доработка», «Принято» |
| Пиковая нагрузка | До 1000 студентов и 150 преподавателей, работающих одновременно (NFR-01) |
| Закрытый контур | Локальные сетевые ресурсы университета; внешний облако-экспорт запрещён (CON-01) |
| Единый портал | Корпоративная система авторизации университета (LDAP/AD, OAuth2/SAML) |
| Руководитель | Научный руководитель курсовой работы (преподаватель) |
