# Бэклог первой версии: система учёта курсовых работ

Задачи упорядочены по зависимостям; приоритеты — MoSCoW. Колонка «Откуда» ссылается на требования `specification.md`. Каждая задача снабжена демонстрацией (как показать, что сделано) и критерием приёмки (по какому наблюдению считаем выполненной).

## 1. Задачи

| № | Задача | Приоритет | Демонстрация | Критерий приёмки |
|---|---|---|---|---|
| Б1 | Настройка локального хранилища | Must | Загрузка тестового текстового файла в хранилище и скачивание его оттуда же | Загруженные файлы доступны для просмотра и скачивания |
| Б2 | Отображение загруженных файлов в виде таблицы с определёнными полями | Must | Открыть главную страницу сервиса | Отображается таблица с полями: «ФИО студента», «Файл», «Дата загрузки», «Преподаватель», «Статус» |
| Б3 | Подключение системы авторизации университета | Must | Авторизация с использованием корпоративной почты и пароля учётной записи студента/преподавателя | Вход в систему осуществляется только через единый портал университета |
| Б4 | Добавление возможности проставить статус работы | Must | Проставление нового статуса через выпадающий список | После обновления страницы сохраняется последний выставленный статус |
| Б5 | Экран мониторинга для завкафедрой | Must | Авторизоваться под записью с правами «Заведующий кафедрой» и открыть главную страницу | Виден список всех студентов, загруженных работ и преподавателей, а также сроки загрузки файлов. Цветная индикация отображает состояние работы (зелёный — принято, жёлтый — в работе, красный — не сдано) |
| Б6 | Генерация файла Excel с соответствующим макетом | Must | Нажать кнопку «Сформировать отчёт» | Скачивается файл без данных, но с очерченными колонками, местом под дату и подпись |
| Б7 | Выгрузка данных в отчёт | Must | Выбирается период и нажимается кнопка «Сформировать отчёт» | Скачивается файл с данными за указанный период, колонки «ФИО студента», «ФИО преподавателя», «Дата и время сдачи», последняя колонка отформатирована как Дата |
| Б8 | Ограничение загрузки файлов | Should | При попытке загрузки файла >10 МБ отображается ошибка | Файлы тяжелее 10 МБ не могут быть загружены |
| Б9 | Организация хранения предыдущих версий работ | Should | Загрузка новой версии файла, просмотр прошлой версии, скачивание и проверка файла | Все предыдущие версии хранятся без перезаписи |
| Б10 | Добавление комментария к статусу | Should | При переключении статуса добавить письменный комментарий | В уведомлении студенту к статусу добавился комментарий преподавателя |
| Б11 | Интеграция системы уведомлений | Should | Загрузка новой работы и смена её статуса | На почту преподавателю пришло уведомление о новой работе. На почту студенту пришло уведомление об обновлении статуса проверки |
| Б12 | Сброс статуса при загрузке новой версии документа | Should | Загрузить новую версию работы | У новой версии статус сброшен до статуса по умолчанию |
| Б13 | Согласование интерфейса со стилем других сервисов университета | Should | Открыть сервис | Все элементы интерфейса и цветовая палитра выполнены в фирменной палитре университета, присутствует логотип и название университета в шапке сайта |
