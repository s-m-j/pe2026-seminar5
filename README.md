# Система учёта курсовых работ

Учебная спецификация: студенты сдают курсовые не по почте, а через сервис кафедры. Документ создан по итогам интервью с заказчиком (карточка 1, занятие 2.1) и доработан по рецензии.

## Устройство репозитория

| Файл | Что содержит |
|---|---|
| `specification.md` | Требования FR-01…FR-08, NFR-01…NFR-02, ограничения CON-01…CON-02, «вне рамок», открытые вопросы |
| `backlog.md` | Задачи Б1–Б13: приоритеты MoSCoW, демонстрация, критерий приёмки, зависимости |
| `glossary.md` | Термины предметной области |

## Правила работы

- Изменения в `main` напрямую не вносятся: работаем через ветку и pull request.
- Заголовок и описание PR обязаны говорить, какую задачу решает изменение.
- Замечание в ревью указывает на конкретную строку и на то, что именно неясно или с чем рассогласовано.
